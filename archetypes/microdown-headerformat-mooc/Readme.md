This archetype is for beamer-based slides using microdown with top level headers as slide definition marker.


Here is an example of two slides

```
{
"title" : "Advanced Object-Oriented Design",
"slidesid":"2023"
}

# First slide

What a beautiful slide

- First column
- 1122
- 1133


# Second slide

<!columns

<!column|width=50

- First column
- 1122
- 1133
!>

<!column|width=50

- Second column
- 2222
- 2233
!>
```
