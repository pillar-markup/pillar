This book is both a short guide to Microdown and a working example of a book written with it.
Its source shows every element it describes, and Pillar builds it as a PDF (`pillar build pdf`) and as a web site
with one page per chapter (`pillar build site`).

Read it next to its source: each chapter is a file in the `Chapters` folder, included here with `inputFile`.
